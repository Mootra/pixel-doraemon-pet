# 哆啦A梦伙伴

这是一个仅限 Windows 的个人 Codex 插件：它通过生命周期钩子驱动一个独立、透明的哆啦A梦悬浮宠物。它不会替换或控制 Codex 内置宠物；若不想同时看到两个宠物，请隐藏其中一个。

## 互动方式

- 拖动：移动伙伴位置。
- 单击：挥手并打开气泡；气泡已显示时，再次单击切换到下一页。
- 双击：使用竹蜻蜓。
- 右键：打开哆啦A梦风格菜单，可使用道具、暂停动画、刷新额度、打开专注后台、设置、重启或退出。
- 启动：Codex 会在会话开始或插件更新后自动沿用最近选择的 v2 或 v3 实例；安装器会分别创建“启动哆啦A梦伙伴”（固定 v2）和“启动哆啦A梦 V3伙伴”（固定 v3）两个图形入口。两者使用不同的配置和 PID 目录；启动另一个版本时会安全切换，始终只保留一个伙伴，避免专注计数重复。
- 管理：右键可立即刷新额度、重新加载图集、打开用户配置、重启或退出。
- 空闲：利用 v2 方向帧注视鼠标。
- 素材更新：v2 入口固定读取已安装的 `pixel-doraemon`，v3 入口固定读取 `pixel-doraemon-v3`，定期检测各自素材变化。
- 动作：以哆啦A梦头部中心计算经过 DPI 校正的鼠标方向，采用进入/退出距离与角度滞后避免抖动，并每 50ms 按最短路径推进一帧。
- 气泡轮换：每 4 秒轮换已启用的数据页。默认显示 Codex 剩余额度、本次连续专注和今日键盘敲击数；关闭额度功能时，专注与敲击页仍可独立显示。正常显示持续 12 秒；首次单击打开第一页，后续单击切换下一页。额度数据来自本地 Codex App Server，不读取或保存账户令牌。
- 专注计时：键盘按下或鼠标点击会开始本次连续专注；连续 60 秒没有这两种操作，本次专注和当前 30 分钟轮次进度才一起归零，今日和累计专注也暂停增长。完成 30 分钟只重置当前轮次进度，不会截断本次连续专注。气泡大数字显示本次专注，下方小字只显示今日专注和累计专注。`focus-state.json` 保存两套计时以及当天总时长和全局键盘敲击次数。键盘计数覆盖所有应用，但只保存数字，不读取输入文本、窗口标题或按键内容。
- 成长历程：每完成一轮 30 分钟专注，显示 8 秒庆祝气泡。累计专注在 30 分钟、2 小时、5 小时、10 小时解锁节点；敲击在 100、1,000、5,000、10,000 次解锁节点，此后每多累计 10,000 次都会再次祝贺。若同时达成多个事件，庆祝气泡会排队展示而不会被覆盖。
- 专注后台：右键宠物后打开，可查看当天有效专注、当前轮次、完成轮次、按应用统计、键盘统计、累计总量和最近历程。

首次启动时，插件会将 `config/default-config.json` 复制到可写数据目录中的 `config.json`。可修改该用户配置来调整动画速度、动作停留时间、事件映射或气泡。`usage.enabled` 只控制 Codex 额度读取与额度页；`bubble.enabled` 独立控制整个信息气泡。气泡启动时立即显示，之后按 `bubble.displayIntervalMs`（默认 5 分钟）显示；`bubble.displayDurationMs` 默认 12 秒，`bubble.bubblePageDurationMs` 默认 4 秒，`bubble.bubbleBackgroundOpacity` 默认 0.82。旧配置里仍放在 `usage` 下的气泡参数会继续兼容读取。

`focus` 部分控制本地专注计时器。`idleThresholdSeconds` 默认 60 秒；键盘按下或鼠标点击会立即开始本次专注，连续超过 60 秒没有这两种操作即结束本次专注并归零。鼠标移动、仅将窗口置于前台不会续时。`pomodoroMinutes` 默认 30。`celebrations.enabled` 独立控制庆祝气泡，`celebrations.durationMs` 控制持续时间；关闭它不会停止轮次和里程碑记录。每日状态和跨天累计数据保存在 `%LOCALAPPDATA%\PixelDoraemonCompanion\`，包括今日专注、总专注时长、总敲击次数、完成轮次与里程碑历史；插件缓存更新后仍会保留。该目录只保存汇总数字和事件标题，不包含具体按键内容。

旧版用户配置中缺失的新设置会自动从 `default-config.json` 读取默认值。右键菜单可重新加载图集或请求新的 Codex 额度快照。

`motion.profileVersion` 用于区分与图集动作相匹配的逐帧节奏。旧配置缺失该版本或版本不一致时，悬浮宠物会自动采用当前图集的新版默认节奏，避免新版动作仍被旧版等速时序播放；当版本一致时，用户自定义的 `frameDurationsMs` 才会生效。

Codex 要求先审核并信任插件钩子，之后才能运行。悬浮宠物使用 Windows PowerShell/WPF，以及一个随插件提供的 Node 辅助程序；辅助程序向本地 Codex App Server 请求与 Codex 客户端相同的额度快照。

构建或更新 v2、v3 两个 Windows 图形启动器，以及各自的桌面和开始菜单快捷方式：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-launcher.ps1
```

`Start-Doraemon-Companion.cmd` 固定启动 v2，`Start-Doraemon-Companion-V3.cmd` 固定启动 v3；推荐使用生成的两个图形启动器手动启动。
